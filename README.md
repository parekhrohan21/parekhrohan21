### About Me

First-Class Computer Science graduate from the **University of East London**, focused on building high-performance systems at the intersection of **FinTech**, **Data Science**, and **DevOps**. My undergraduate dissertation modelled cryptocurrency price movements using machine learning and tweet sentiment analysis (VADER, TextBlob, FLAIR).

- **Current Build:** [Pit Wall](https://github.com/parekhrohan21/fastf1_pitwall) — a Formula 1 telemetry and race strategy dashboard built with Python, Streamlit, FastF1, and Plotly.
- **Industry Simulations:** Completed virtual engineering programmes via **Forage** with **Citi** (coffee futures option pricing) and **Wells Fargo** (Spring Boot financial data layer).
- **Focus Areas:** Machine learning, quantitative finance, containerised workflows (Docker, Dev Containers, GitHub Actions), networking, and software architecture.
- **Outside Tech:** Die-hard Formula 1 fan supporting the **McLaren F1 Team** (Team Papaya).
